Which file is which

init.el symlink, git-ignored
Points at init.macos.el on the Mac and init.linux.el on Linux. SPC f e d opens it (you land in the real file). Switch with ln -sfn init.linux.el init.el.
init.macos.el / init.linux.el tracked
Full Spacemacs dotfiles with the template's explanations kept. Only OS-specific values differ: font, line numbers, undo system, Homebrew/GNU-ls paths, iCloud org folder. Paste snippets here as before.
layers/sdev/ tracked
Everything shared: Python/Rust servers, the lsp tuning that stops the freezes, conda/venv switching, SPC h h, SPC j m, , p. SPC h l then sdev shows its README.
local.el optional, git-ignored
Per-machine overrides, loaded last. Copy local.el.example. Typical: type checking on, a fixed python path, clippy instead of cargo check.

Python

Open any .py file. Both servers start by themselves; the mode line shows LSP[pyright:…][ruff:…].

  1. First file of a project: lsp-mode asks where the project root is (Select action). Press i once; it remembers. Same question as before the overhaul.
  2. Interpreter: the venv you activated with SPC m v w (the list comes from WORKON_HOME, your conda envs directory is detected), else ./.venv or ./venv inside the project (what uv venv creates), else python on PATH. After SPC m v w the servers of the buffer restart on their own.
  3. What the squiggles mean: ruff reports lint (F401 unused import, E702 …) and honours the project's pyproject.toml/ruff.toml (Megatron-LM selects only S506, so you see almost nothing there; that is their config, not a fault). basedpyright reports syntax errors, undefined names and unresolved imports. Type errors are off by default; (setq lsp-pyright-type-checking-mode "basic") in local.el turns them on.

JSON

JSON files open in json-mode with syntax checking (flycheck) and no language server, so node is not needed. Formatting is done by Emacs itself and works on the selected region or, with no selection, the whole buffer.

KeyWhat it does

, = sPretty-print with keys sorted
, = mMinify to one line
, T hBrowse the JSON as a tree (json-navigator)

Rust

Open a .rs file inside a Cargo project; rust-analyzer starts (answer i the first time). Diagnostics come from cargo check on every save. rust-analyzer watches the files itself, Emacs does not.

KeyDoes
SPC m = =rustfmt the buffer (not on save).
SPC m g g · SPC m h h · SPC m r rDefinition · documentation · rename.
SPC m c c · SPC m c t · SPC m c rcargo build · test · run (rustic).
SPC m a aCode actions (imports, fixes).

Clippy instead of check: (setq lsp-rust-analyzer-cargo-watch-command "clippy") in local.el.

Switching machines

# new Linux box or container
git clone <GitConfig> ~/sg21CodeLab/GitConfig
ln -s ~/sg21CodeLab/GitConfig/spacemacs ~/.spacemacs.d
cd ~/.spacemacs.d && ln -sfn init.linux.el init.el
git clone -b develop https://github.com/syl20bnr/spacemacs ~/.emacs.d
~/.spacemacs.d/scripts/install-lsp-servers.sh
emacs            # first start installs ~290 packages (6 min from the TUNA mirror)

# the Mac (after you say go)
cd ~/sg21CodeLab/GitConfig && git checkout spacemacs-overhaul
~/.spacemacs.d/scripts/mac-switch.sh     # backs up ~/.emacs.d, installs the new one, links init.macos.el
open /opt/homebrew/Cellar/emacs-plus@30/30.2/Emacs.app

Container for trying things without touching anything: ~/.spacemacs.d/docker/run.sh (Debian 13, Emacs 30, uv, rustup; mounts this directory).

Upgrading

  • Servers: ~/.spacemacs.d/scripts/install-lsp-servers.sh (runs uv tool upgrade).
  • Spacemacs: cd ~/.emacs.d && git pull, then SPC f e U for packages. Check the startup note afterwards.
  • Emacs (Mac): brew upgrade emacs-plus@30. Packages are per Emacs version (elpa/30.2/), so a new minor version recompiles them once.
  • Config: edit init.macos.el / init.linux.el or layers/sdev/config.el, commit, pull on the other machines.

When something is off

SymptomCheck
No completion in a .py fileSPC m b d: are pyright and ruff listed? If not, basedpyright-langserver --version in a shell; the script installs it. Then SPC m b r.
Imports marked unresolvedThe server is using the wrong python. SPC m v w to pick the env, or put lsp-pyright-python-executable-cmd in local.el.
Asked for the project root again and againYou answered n. Next time press i (remembered in .cache/lsp-session-v1).
Emacs feels slow in a repoSPC m b d shows one server per project; M-x lsp-workspace-shutdown on ones you are done with. Memory per basedpyright server on vllm/verl-sized repos is about 2 GB.
Rust: no diagnosticsThey appear after save (cargo check). *rust-analyzer::stderr* has the log.
Need the protocol log(setq lsp-log-io t) in local.el, restart servers, read *lsp-log*.
Want the old setup backMac: scripts/mac-switch.sh --undo ~/.emacs.d.bak-<date> and git checkout master. Nothing was deleted.
