# ~/.spacemacs.d

Spacemacs private configuration, shared by every machine (macOS laptop,
Linux boxes, the `dev-tokyo` container). `~/.spacemacs.d` is a symlink to
this directory; Spacemacs loads `init.el` from it.

## Layout

| Path | What it is |
|------|------------|
| `init.el` | The one dotfile. Layers, Spacemacs settings, keys, Python/Rust/LSP setup. Sections are marked with `;;;;` headers. |
| `local.el.example` | Template for `local.el`, an untracked per-machine override file loaded at the end of `init.el`. |
| `layers/sdefaults/` | Small tweaks to packages other layers own (recentf, helm, evil keys, spaceline), plus plain settings in `config.el`. |
| `layers/sdired/` | dired extras: vendored `dired+` (`local/dired+/dired+.el`) and `P` = parent directory following symlinks. |
| `snippets/` | Private yasnippet snippets, loaded automatically. |
| `scripts/install-lsp-servers.sh` | Installs basedpyright + ruff into a private venv and links them into `~/.local/bin`; adds rust-analyzer via rustup. |
| `scripts/install-source-code-pro-font.sh` | Font installer for new Linux machines. |
| `docs/spacemacs-review.html` | The 2026-10 review: findings, plan, what each commit changed. |
| `.spacemacs.env` | Generated by Spacemacs from the login shell. Git-ignored, never edit by hand (`SPC f e e` to regenerate). |

## New machine

```sh
git clone <this repo> ~/sg21CodeLab/GitConfig
ln -s ~/sg21CodeLab/GitConfig/spacemacs ~/.spacemacs.d
~/.spacemacs.d/scripts/install-lsp-servers.sh   # basedpyright, ruff, rust-analyzer
cp ~/.spacemacs.d/local.el.example ~/.spacemacs.d/local.el   # optional overrides
```

Then start Emacs. Spacemacs installs the missing packages on first start.

## Python and Rust

* Python: `basedpyright` (completion, goto, hover, rename, syntax and
  undefined-name errors) + `ruff server` (lint, `SPC m = =` format,
  organize-imports code action). Both are started by lsp-mode when a
  `.py` file is opened. Type checking is off by default; set
  `my/python-typecheck-mode` to `"basic"` in `local.el` to turn it on.
* Switching conda env: `SPC m v w` (lists `~/mambaforge/envs`), the
  servers of the current buffer restart automatically.
* Rust: `rust-analyzer` from rustup, `cargo check` on save for
  diagnostics. rust-analyzer watches the files itself.
* Something off? `SPC m b d` describes the session, `SPC m b r` restarts
  the servers, `*lsp-log*` has the protocol log when `lsp-log-io` is t.

## Rolling back

Every change since the 2026-10 review is one commit on the
`spacemacs-overhaul` branch; `git log -- spacemacs/` explains each one.
`git checkout master -- spacemacs/` restores the previous files (the old
`init.el` symlink pointed at `.spacemacs.mac`).
