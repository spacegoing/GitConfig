# ~/.spacemacs.d

Spacemacs private configuration, shared by every machine (macOS laptop,
Linux boxes, the `dev-tokyo` container). `~/.spacemacs.d` is a symlink to
this directory; Spacemacs loads `init.el` from it.

Target: Spacemacs **develop** branch, Emacs **30**.

## One dotfile per OS, switched with a symlink

```
init.el -> init.macos.el      # on the Mac
init.el -> init.linux.el      # on Linux / in containers
```

`init.el` is git-ignored: each clone picks its own target with

```sh
cd ~/.spacemacs.d && ln -sfn init.linux.el init.el     # or init.macos.el
```

Both files are complete Spacemacs dotfiles generated from the develop
template (all the template's comments are kept, so copy-pasting snippets
into them works as before). They hold only what differs per OS: font, line
numbers, undo system, Homebrew/GNU-ls paths, iCloud org directory. Everything
shared lives in private layers, so the two files cannot drift apart again:

| Layer | What it holds |
|-------|---------------|
| `layers/sdev/` | Python (basedpyright + ruff server) and Rust (rust-analyzer) setup, the lsp-mode tuning that keeps big repos from freezing, conda/venv switching, `SPC h h`, `SPC j m/M`, `, p`, `, h s`. |
| `layers/sdefaults/` | recentf, evil keys, helm, spaceline, fill-column, dired defaults. |
| `layers/sdired/` | vendored `dired+`, `P` = parent directory following symlinks. |

## Layout

| Path | What it is |
|------|------------|
| `init.macos.el`, `init.linux.el` | The two dotfiles (see above). |
| `init.el` | Git-ignored symlink to one of them. |
| `local.el.example` | Template for `local.el`, an untracked per-machine override file loaded at the end of the dotfile. |
| `layers/` | Private layers, see table above. Each has a `README.org`. |
| `snippets/` | Private yasnippet snippets, loaded automatically. |
| `scripts/install-lsp-servers.sh` | basedpyright + ruff via `uv tool install` (into `~/.local/bin`), rust-analyzer via rustup. Re-run to upgrade. |
| `scripts/mac-switch.sh` | Moves this Mac from the old `~/.emacs.d` to the prepared Spacemacs develop checkout (`~/.emacs.d-next`) and points `init.el` at the macOS dotfile. Has `--undo`. |
| `scripts/install-source-code-pro-font.sh` | Font installer for new Linux machines. |
| `docker/` | `Dockerfile` + `run.sh`: Debian 13 / Emacs 30 container used to develop and verify this config without touching the host Emacs. |
| `docker/ubuntu24/` | `Dockerfile` + `bake.sh` + `run.sh`: the `spacemacs-u24` image on Ubuntu 24.04 (same Ubuntu as `verlai/verl`). Emacs 30.2 built from source, this config, every package installed and native-compiled at build time; a container starts with no downloads. See `docs/spacemacs-u24-dev-notes.html`. |
| `docs/` | `spacemacs-review.html` (2026-10 review, phase 1), `spacemacs-overhaul-report.html` (phase 2: container-verified rebuild, every commit), `spacemacs-manual.html` (what is installed, what to press, what changed), `spacemacs-u24-dev-notes.html` (the Ubuntu 24.04 image on the Tokyo box). |
| `.spacemacs.env` | Generated by Spacemacs from the login shell. Git-ignored, never edit by hand (`SPC f e e` to regenerate). |

## New machine

```sh
git clone <this repo> ~/sg21CodeLab/GitConfig
ln -s ~/sg21CodeLab/GitConfig/spacemacs ~/.spacemacs.d
cd ~/.spacemacs.d && ln -sfn init.linux.el init.el          # or init.macos.el
git clone -b develop https://github.com/syl20bnr/spacemacs ~/.emacs.d
~/.spacemacs.d/scripts/install-lsp-servers.sh               # basedpyright, ruff, rust-analyzer
cp ~/.spacemacs.d/local.el.example ~/.spacemacs.d/local.el  # optional overrides
```

Then start Emacs (30.x). Spacemacs installs the missing packages on first start.

## Python and Rust

* Python: `basedpyright` (completion, goto, hover, rename, syntax and
  undefined-name errors) + `ruff server` (lint, `SPC m = =` format,
  organize-imports / fix-all code actions). Both start when a `.py` file is
  opened. Type checking is off by default; `(setq lsp-pyright-type-checking-mode "basic")`
  in `local.el` turns it on.
* Interpreter: the venv activated with `SPC m v w` (lists `$WORKON_HOME`, the
  conda envs dir is detected), else `./.venv` or `./venv` in the project
  (uv convention), else `python` on PATH. After `SPC m v w` the servers of
  the current buffer restart by themselves.
* Rust: `rust-analyzer` from rustup, `cargo check` on save for diagnostics.
  rust-analyzer watches the files itself.
* Something off? `SPC m b d` describes the session, `SPC m b r` restarts the
  servers, `*lsp-log*` has the protocol log when `lsp-log-io` is t.

## Container

```sh
REPOS=/path/with/test/repos ~/.spacemacs.d/docker/run.sh   # builds, starts, attaches
# inside: git clone -b develop https://github.com/syl20bnr/spacemacs ~/.emacs.d ; emacs -nw
```

The container mounts this directory at `/root/.spacemacs.d`, so edits are
shared with the host and `init.el` must point at `init.linux.el`.

## Rolling back

Every change since the 2026-10 review is one commit on the
`spacemacs-overhaul` branch; `git log -- spacemacs/` explains each one.
`git checkout master -- spacemacs/` restores the previous files (the old
`init.el` symlink pointed at `.spacemacs.mac`). On the Mac,
`scripts/mac-switch.sh --undo <backup>` brings the old `~/.emacs.d` back.
